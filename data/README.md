# Data

No experimental data are included in this repository.

Place local, ignored adapters or downloaded data below this directory. A public
analysis contribution should commit only:

- an accession and license;
- checksums or a machine-readable provenance manifest;
- deterministic download/preprocessing instructions where redistribution is
  permitted;
- source-to-canonical-schema adapter code.

See [`../docs/data_contract.md`](../docs/data_contract.md).
